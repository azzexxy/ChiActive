Why get a Google Gemini API key?

Your class OpenRouter key has a $1 limit and a 24-hour lifetime. A key from your own Google AI Studio account gives you another way to try the activity:

  • Separate usage: If your class key runs out or expires, you can try a Google free-tier key. Google has its own rate limits, so this does not provide unlimited use.
  • Compare models: Try the same small design task with Gemini 3.8 Flash and a class model such as Flash-Lite. Compare the browser result and the follow-up each needs.
  • Free-tier option: Google's pricing page lists Gemini 3.8 Flash on the free tier. Check that your project's Plan says Free and do not turn on billing for this exercise.
1

Visit Google AI Studio

Google AI Studio is Google's web portal for developers and students to access Gemini AI models directly.

https://aistudio.google.com/api-keys
Open AI Studio ↗
  1. Click the link above to open Google AI Studio in a new tab.
  2. Sign in with your standard Google Account (you can use your university email or your personal Google account).
  3. If this is your first visit, review and accept the Terms of Service to continue to the dashboard.
2

Create your free API key

Once you are on the API Keys page in Google AI Studio:

  1. If Google has already created a key for your account, you may use it if its project's Plan says Free. Otherwise, click Create API key and follow Google's prompts for a new project.
    Stay on the Free plan: Check the Plan column for the project linked to your key. Do not select Set up billing for this class activity.
  2. Copy the key from the API Keys page. It usually begins with AIza.
Security tip: Your API key is your personal credential. Keep it private, never share it with others, and never paste it into public websites or commit it to GitHub.
3

Put your key into Goose Desktop

Now configure Goose Desktop to use Google Gemini with your newly created API key:

  1. Open the Goose Desktop application on your computer.
  2. Navigate to Settings (click the gear icon or select Settings from the sidebar menu).
  3. Go to the Models tab.
  4. Click Configure Providers.
  5. Select Google Gemini from the list of available model providers.
  6. In the API Key input box, paste your Google AI Studio API key.
  7. Save or submit the configuration.
Using another AI tool?
  • Goose CLI: Run goose configure, select Configure Providers → Google Gemini, and paste your key. Goose also recognizes the GOOGLE_API_KEY environment variable.
  • Another coding tool: Check whether that tool supports a personal Google Gemini API key, then follow its own provider setup instructions.
4

Set your primary model: Default to Gemini 3.8 Flash

In Goose Desktop (under Settings → Models) or your AI coding assistant, set your default model to:

gemini-3.8-flash

Why try Gemini 3.8 Flash?

  • Google describes it as a Flash model built for complex software and agent tasks. Try it on a design change that involves more than one page.
  • Compare its output with the class Flash-Lite model on the same small request. Judge the visible result and how much correction each needs.

If you reach a Google rate limit

Pause and check your active limits in Google AI Studio. You can also switch back to a class model while your class key remains valid. Available limits depend on your account and model.

Start a fresh session for a new task

Long coding sessions can use more of your model's context and token allowance. Save your work and start a fresh Goose session when you move to a different task.

In the Goose CLI, /clear clears the current chat history. In Goose Desktop, start a new session for the next task.

5

Test your setup and compare models

Open the Website Design workspace folder in Goose. Try this same small task with Gemini 3.8 Flash and the class Flash-Lite model. Use separate copies of the site or undo the first model's changes before trying the second.

Read `brand-guidelines.md`. Improve one product card in `starter-site/jackets/index.html` using ChiActive's colors and clearer spacing. Edit only files inside `starter-site/`, then tell me what you changed.

Things to notice when comparing models:

  • Visible result: Which product card is easier to scan and fits ChiActive's colors?
  • Working code: Do images, links, and the layout still work when you refresh the page?
  • Follow-up effort: Which model needed fewer corrections to reach a result you like?

Frequently Asked Questions

Is anything I send through Google AI Studio private?

Google's terms for unpaid services allow submitted content and responses to be used to improve its products. Use class-approved practice material, and do not submit sensitive personal information, passwords, personal API keys, or confidential files.

Does Google AI Studio ever charge me?

Google offers a free tier for Gemini 3.8 Flash. Check that the project linked to your key shows Free in AI Studio, and do not enable billing for this exercise. A key linked to a paid project can incur charges. Free-tier requests still have rate limits.

What should I do if I see a "429 RESOURCE_EXHAUSTED" error?

Pause and check your active rate limits in Google AI Studio. You can continue with an available class model while that key is valid, or return to the Google model after its limit resets.

Can I switch back and forth between my class key and Gemini?

Yes! In Goose Desktop, you can easily switch active models and providers under Settings → Models at any time. This makes it easy to compare how different models perform on the exact same design task.

Where can I view my site after making changes?

Run your local preview server using start-server-mac.command (Mac) or start-server-windows.bat (Windows) and open http://localhost:8000 in your browser. Refresh after each AI change to see your new storefront live.
