Intro to Interactive Marketing

ChiActive website design activity

Use the brand your class created to redesign a practice storefront with an AI coding assistant. You will work on files on your own computer.

1. Instructions 2. Find your API key 3. Free Google Gemini Key 4. View starter site

What you are making

Use the brand in brand-guidelines.md to turn starter-site/ into your own effective shopping experience. You can change layouts, navigation, and content and add new pages. Your changes stay in this practice copy; they do not edit the live store.

Before you begin: choose a model to try

You have two ways to use Goose for this activity. You can start with either one, and you can try both.

  • Class key: Find your OpenRouter key and use one of the class models shown there, including Flash-Lite. This key has a $1 limit and expires after 24 hours.
  • Your own Google key: Follow the Google AI Studio guide to create a key and try gemini-3.8-flash. This uses a separate Google free-tier quota, which also has rate limits.

For a useful comparison, give both models the same small design request, review the changes each makes, and decide which result helps you more.

1

Get your files ready

Download the Website Design ZIP from your class site, then unzip it. Open the resulting Website Design folder. Keep everything inside that folder together.

2

Set up an AI coding assistant

If you already use an AI coding tool, you can use it for this project. Open the whole Website Design folder in that tool.

If you need one, download Goose Desktop for macOS or Windows and open it. Use the desktop version; no terminal setup is needed.

You need an AI coding tool that can read and edit files in the folder. An ordinary chat window that cannot access your local files will not be able to make the site changes for you.
3

Set up the key you chose

Option A: Use the class OpenRouter key

  1. Open the API key page.
  2. Search for your name or student ID and click Copy Key.
  3. In Goose Desktop, choose Other Providers → OpenRouter on first launch and paste the supplied key. If Goose is already set up, use Settings → Models → Configure providers → OpenRouter.
  4. Choose one of the class models listed on the key page. If it is not in the list, choose the option to enter a custom model name.
Use your class key instead of Goose's automatic OpenRouter sign-in, which is for a personal OpenRouter account. Each class key has a $1 limit and lasts 24 hours; the key page shows its expiration time.

Option B: Use your own Google AI Studio key

Open the Google key guide and follow its steps to create a key, configure Google Gemini in Goose, and select gemini-3.8-flash. Check that the Google project is on the free tier. Its usage limits are separate from the class key.

4

Start the redesign

Open Website Design as the assistant's working folder. Paste this prompt into your AI coding tool:

Read `README.md` and `brand-guidelines.md`, then inspect the pages and assets in `starter-site/`, including the logo in `starter-site/images/` and local fonts in `starter-site/fonts/`. Start by applying the ChiActive colors, fonts, logo, and direct, encouraging, outdoorsy voice to the homepage and shared styles. Edit only inside `starter-site/`. You may redesign layouts, change navigation and content, and add pages as long as the site still works. Show me your first changes and tell me how to preview them.

Review the first result, then work through the design ideas below one at a time. Give the assistant specific follow-up requests in your own words.

All website changes belong inside starter-site/. You may create new pages and reorganize the site; update its links when you do.
5

Build out your version of ChiActive

These are starting points, not a limit on what you can do. Preview the site after each round and decide what to improve next.

  1. Compare the models.

    Ask Flash-Lite with your class key and Gemini 3.8 Flash with your Google key to tackle the same small task, such as improving a product card. Compare the page in your browser, the quality of the code, and how much follow-up help each model needs. Use separate copies or undo the first change before running the second so you can compare fairly.

  2. Apply the colors and fonts.

    Use the class color palette, fonts, logo, and brand voice throughout the site. The logo and font files are already in starter-site/images/ and starter-site/fonts/.

  3. Add images and useful icons.

    Find free-to-use stock images online or make images with an AI image tool. Save new images in starter-site/images/ and ask your coding assistant to place them where they help tell the brand story. Add a consistent set of icons where they make actions or categories clearer.

  4. Build a shopping cart.

    Ask your coding assistant to make a working cart for this static practice site. Visitors should be able to add products, change quantities, remove items, and see totals. The cart can save its contents in the browser between refreshes. It is a demonstration cart, so no real payment processing is needed.

  5. Write and refine content.

    Use other AI tools to brainstorm or draft homepage, product, About, or blog content. Review the wording and product claims yourself. Then ask your coding assistant to insert and refine the copy so it fits ChiActive's voice.

  6. Rethink the homepage and navigation.

    Improve the current homepage layout or replace it entirely. Change the featured content and main navigation if you think a different structure would work better. You can add as many helpful pages as you want; connect them with working links.

  7. Keep exploring.

    Make any other changes that would help visitors understand the brand, find products, and feel confident using the site. Be ready to explain the choices you made.

6

Preview and review your work

On a Mac, double-click start-server-mac.command. On Windows, double-click start-server-windows.bat. Keep the window that opens running, and view the site at http://localhost:8000. Refresh the browser after each change.

If the launcher does not work, use your editor's local preview feature or ask your AI tool to start a local web server for starter-site/.

7

Package and submit your work

When you are satisfied with your storefront redesign, package your work into a single ZIP file to ensure all your pages, styles, images, and fonts are preserved together without missing files:

  1. Compress your folder into a ZIP file:
    • On macOS: Right-click (or Control-click) your Website Design folder in Finder and choose Compress "Website Design". Rename the resulting zip to include your name (e.g. ChiActive-YourName.zip).
    • On Windows: Right-click your Website Design folder in File Explorer, choose Compress to ZIP file (or Send to → Compressed (zipped) folder), and rename it with your name.
  2. Upload to your student folder on Google Drive:

    Your instructor has created a dedicated Google Drive folder organized with individual subfolders for each student:

    Open Class Google Drive Submissions ↗

    Locate the subfolder labeled with your name and upload your finished .zip file there.

Why submit as a ZIP? Uploading individual uncompressed files or folders through a web browser often misses nested subdirectories (such as starter-site/images/ or fonts/) or breaks relative file paths. A ZIP file ensures your entire project stays complete and intact.

Before you finish

  • Check the homepage, shopping pages, cart, and any pages you added.
  • Make sure images and icons load, navigation links work, and the cart responds as expected.
  • Read the content aloud and confirm that it fits ChiActive's voice and makes accurate claims.
  • Compress your folder into a ZIP file and upload it into your designated personal folder in Google Drive.
