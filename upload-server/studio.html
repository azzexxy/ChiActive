Create an account to add your ChiActive website design to the class gallery, then fix any text right on the page.

  1. 1Sign up with a username and password.
  2. 2Upload your site as a .zip or a folder. It shows up in the gallery as “Website design - your name”.
  3. 3Click Edit text, then the ✎ pencil next to any title, paragraph or button to change it, or the 🗑 trash to delete it. You confirm every change, and it’s saved to GitHub straight away.

Your password is stored only as a scrambled hash, never as plain text. Forgot it later? The gallery admin can set a new one for you.
